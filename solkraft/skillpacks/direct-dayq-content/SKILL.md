# DayQ Fallout Content Director

Turn a user or agent request into an implementation-ready brief connecting canon, physical construction, survival, persistence, multiplayer, art production, and validation.

Read [dayq-canon.md](references/dayq-canon.md) before substantive work. Treat it as binding unless the user explicitly changes it.

## Method

1. Classify the request: object/loot, structure/location, vehicle/machinery, character/faction, ecology, mission/event, base module, world system, elite enclave, or bunker operation.
2. Build a causal chain: pre-collapse purpose -> first 15 days -> day-30 warlord transition -> three-year assault -> later users -> year-28 condition -> player interactions -> persistent consequences.
3. Connect relevant survival, scarcity, contamination, degradation, combat/stealth, faction economics, ownership, and environmental storytelling.
4. Specify rules, components, states, failure, repair, salvage, permissions, replication, persistence, exploits, progression, metadata, engine integration, and tests.
5. Keep post-quantum technology physical and bounded. Require intelligence, recovered hardware, specialists, fabrication, delivery, local temporary suppression, and occupation logistics.

## Base and raid doctrine

Treat massive persistent base building as a core pillar from hidden camp through outpost, settlement, industrial fortress, and strategic infrastructure holder. Model hauling, compatibility, contamination, power, water, workshops, structural support, permissions, siege, offline protection, and recovery.

For elite enclaves and bunkers include discovery, surveillance, grid mapping, target samples, preparations, interception, shielding, redundancy, temporary breach windows, defenders/automation, interior hazards, alternatives, moral choices, loot, occupation, rival response, and upkeep. Capturing a site begins a new burden.

## Output

Return a cohesive implementation brief and observable acceptance criteria. Avoid generic apocalypse decoration and direct use of living real-world individuals as fictional villains.
