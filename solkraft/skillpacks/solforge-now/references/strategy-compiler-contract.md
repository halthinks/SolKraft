# Native strategy composition

Use the user objective, applicable contracts, observed source state, and available tools to choose work. Select one primary procedure per stage, add distinct support only when useful, and preserve required inputs and exclusions.

Order dependencies before dispatch. Consider expected result quality, evidence, effort, latency, reversibility, and risk; scores are comparisons, not probabilities. A missing tool or dependency is a reported prerequisite, never an invented adapter.

The host agent executes authorized work directly. Routing grants no authority and requires no ordered Next confirmations, approval widget, receipt service, or informational Goal. User corrections invalidate dependent choices only; Pause and Stop halt new work.

Bind completion to actual outputs and observed checks. Compare the chosen route against failure evidence, repair affected work, and stop at demonstrated acceptance or a real external blocker.
