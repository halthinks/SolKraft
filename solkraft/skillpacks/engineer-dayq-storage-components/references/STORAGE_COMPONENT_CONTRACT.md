# Storage Component Contract

Component classes:

- structure: shell, frame, panel, base, reinforcement, upright, beam, brace, deck;
- access: lid, door, drawer, slide, hinge, zipper chain/slider/pull, roll-top, flap;
- retention: latch, hasp, buckle, strap, webbing, hook-loop, cord, net, rail, divider;
- security: key/combination lock, seal, tamper indicator, electronic reader, biometric/PQC module;
- handling: handle, grip, shoulder strap, hip belt, frame, wheel, caster, axle, skid, lift point;
- environment: gasket, liner, insulation, drain, vent, filter, desiccant holder, shielding;
- organization: tray, shelf, parts bin, pouch, magazine insert, foam, label holder;
- installation: foot, bracket, anchor, bolt group, floor/wall/vehicle/exo hardpoint.

Record interface key, load rating, condition, installed orientation, parent identity, repairability and authoritative persistence need.
