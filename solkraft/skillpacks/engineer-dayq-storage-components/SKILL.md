# Engineer DayQ Storage Components

Make every important storage behavior traceable to construction and serviceable parts.

Read [STORAGE_COMPONENT_CONTRACT.md](references/STORAGE_COMPONENT_CONTRACT.md). Use root-material, crafting, manufacturing, material-state, rig/interaction, inventory and persistence owners.

## Workflow

1. Define component purpose, material/process, dimensions, mass, load path, interfaces and tolerances.
2. Assign compatibility keys, installation orientation, tools, station, skill, power, labor and consumables.
3. Define wear, jam, break, tear, deformation, corrosion, contamination and missing-part behavior.
4. Define diagnosis, access, removal, replacement, adjustment and test steps at gameplay abstraction.
5. Link salvage sources, manufactured substitutes, quality grades and reclaimed yield.
6. Define authoritative installed identity/condition where gameplay-relevant; aggregate cosmetic fasteners when safe.
7. Produce sockets, pivots, collision and animation interfaces for asset-family production.
8. Reject components that grant capacity, security, sealing or load rating without a physical mechanism.

## Completion

Deliver component definition, compatibility matrix, recipe/repair/salvage links, failure states, production route, runtime mapping and validation.
