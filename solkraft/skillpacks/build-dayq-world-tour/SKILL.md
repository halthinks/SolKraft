# DayQ Cinematic World Tour

Create an outward-facing pre-rendered presentation layer. Never label scrubbed video as real-time playable footage.

Resolve the DayQ workspace root from `DAYQ_ROOT` or the nearest current-directory ancestor containing `dayq/data`, `dayq/schemas`, and `dayq/skills`. Stop with the missing-root evidence if neither route succeeds.

Read [seam-contract.md](references/seam-contract.md), `$DAYQ_ROOT/dayq/data/DAYQ_CANONICAL_TOUR_SEQUENCE.json`, and `$DAYQ_ROOT/dayq/schemas/DAYQ_CINEMATIC_TOUR_MANIFEST.schema.json`.

## Workflow

1. Select campaign purpose and CTA.
2. Convert canon into an ordered treatment with one visual thesis and narrative job per scene.
3. Lock lens language, motion, palette transition, aspect ratios, typography, factions, architecture, weather, and representation exclusions.
4. Prefer approved Blender or engine renders as anchor frames. Record provenance.
5. Produce scene stills and dive-in clips.
6. Create every connector from the actual accepted last decoded frame of scene N and first decoded frame of scene N+1. Record hashes and similarity results.
7. Produce independent desktop landscape and mobile portrait sequences; do not crop desktop as the mobile master.
8. Implement lazy loading, prefetch, deterministic seeking, seam handling, posters, reduced-motion stills, keyboard support, captions, deep links, analytics, and CTA.
9. Validate every seam, device path, accessibility mode, claim, and link.

Default order: ordinary community -> first 15 days -> day-30 warlord transition -> three-year occupation -> year-28 settlement -> industrial clan fortress -> suppression laboratory -> abandoned elite enclave -> sealed bunker exterior -> descent through the breach.
