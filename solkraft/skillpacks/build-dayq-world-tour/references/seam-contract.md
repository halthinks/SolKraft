# Seam and web contract

- Use accepted decoded boundary frames, not approximate source stills.
- Record boundary hashes and similarity metrics.
- Do not hide broken seams with arbitrary blur.
- Create native landscape and portrait framing, posters, safe areas, and reduced-motion stills.
- Support lazy loading, near-segment prefetch, deterministic seeking, muted autoplay rules, keyboard navigation, captions, and no-motion navigation.
- Track scene reach, completion, CTA exposure/activation, device class, load failure, and reduced-motion use with privacy minimization.
