# DayQ Economy and Progression Modeling

Turn design claims into explicit assumptions, reproducible calculations, sensitivity analysis, and balance decisions.

Read [model-contract.md](references/model-contract.md). Use the spreadsheet skill for spreadsheet artifacts and validate formulas against an independent calculation route.

## Workflow

1. Define units, time horizon, player/clan cohorts, sources, sinks, transfers, losses, storage, and contested access.
2. Separate world creation, player production, trade, destruction, decay, and desired accumulation.
3. Model distributions and behavior ranges, not only averages.
4. Run solo, four-person, twelve-person, and organized-large-clan scenarios.
5. Calculate time to camp, outpost, settlement, industrial stronghold, suppression technology, and bunker readiness.
6. Stress-test hoarding, farming, duplication, market concentration, clan snowballing, abandonment, and server age.
7. Run sensitivity analysis and identify parameters that dominate outcomes.
8. Recommend changes, rerun, and preserve scenario comparisons.

## Balance condition

Over the selected equilibrium window, resource creation should approximately equal destruction plus desired accumulation. Deliberate scarcity may deviate locally or temporarily, but permanent starvation and material saturation require explicit design justification.

## Output

Deliver source assumptions, model code or workbook, scenario results, charts where useful, formula validation, conclusions, and linked balance decisions.
