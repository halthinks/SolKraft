# Science workflows

Select the capability matching the actual task. Read its entrypoint only when needed.

- [solforge-workflow-science-analysis](../../solforge-workflow-science-analysis/SKILL.md): Apply a reproducible analysis plan with assumptions, sensitivity checks, uncertainty, and contrary evidence.
- [solforge-workflow-science-experiment](../../solforge-workflow-science-experiment/SKILL.md): Specify methods, controls, measurements, power assumptions, risks, and verification before execution.
- [solforge-workflow-science-hypothesis](../../solforge-workflow-science-hypothesis/SKILL.md): Derive testable hypotheses from the selected evidence with alternatives, predictions, and falsifiers.
- [solforge-workflow-science-literature](../../solforge-workflow-science-literature/SKILL.md): Run a reproducible source search, evidence table, disagreement analysis, and gap map.
- [solforge-workflow-science-replication](../../solforge-workflow-science-replication/SKILL.md): Reproduce claims independently, compare conditions, quantify divergence, and record unresolved causes.
- [solforge-workflow-science-report](../../solforge-workflow-science-report/SKILL.md): Produce a configured scientific package with methods, results, visuals, limitations, review, and reproducibility assets.
