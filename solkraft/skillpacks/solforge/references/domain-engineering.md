# Engineering workflows

Select the capability matching the actual task. Read its entrypoint only when needed.

- [solforge-workflow-engineering-prototype](../../solforge-workflow-engineering-prototype/SKILL.md): Create a requested prototype or design artifact with simulation, test, rollback, and release boundaries.
- [solforge-workflow-engineering-requirements](../../solforge-workflow-engineering-requirements/SKILL.md): Translate intent into testable requirements, interfaces, constraints, hazards, and verification.
- [solforge-workflow-engineering-trade](../../solforge-workflow-engineering-trade/SKILL.md): Compare design alternatives with common constraints, models, evidence, sensitivity, and risks.
- [solforge-workflow-engineering-verify](../../solforge-workflow-engineering-verify/SKILL.md): Test requirements, tolerances, failure modes, safety assumptions, and reproducibility against evidence.
- [solforge-workflow-launcher-install](../../solforge-workflow-launcher-install/SKILL.md): Design and implement safe acquisition, integrity, prerequisites, install, launch, update, uninstall, troubleshooting, and rollback for verified targets.
- [solforge-workflow-launcher-package-matrix](../../solforge-workflow-launcher-package-matrix/SKILL.md): Build reproducible native, runtime-bundled, container, and ecosystem artifacts without overstating platform support.
- [solforge-workflow-launcher-release-readiness](../../solforge-workflow-launcher-release-readiness/SKILL.md): Reconcile artifacts, checksums, SBOM, provenance, signing readiness, CI, documentation, updates, and support into a truthful release matrix.
- [solforge-workflow-software-mobile-adaptation](../../solforge-workflow-software-mobile-adaptation/SKILL.md): Implement a honest mobile redesign with platform lifecycle, interaction, storage, permissions, packaging, and device verification.
- [solforge-workflow-software-native-port](../../solforge-workflow-software-native-port/SKILL.md): Port shared behavior through explicit native platform adapters and verified target builds.
- [solforge-workflow-software-portability-audit](../../solforge-workflow-software-portability-audit/SKILL.md): Inventory platform coupling and build an evidence-bound compatibility matrix before making target claims.
- [solforge-workflow-software-shared-core](../../solforge-workflow-software-shared-core/SKILL.md): Separate portable behavior from target-specific UI, lifecycle, storage, permissions, and native integration.
- [solforge-workflow-software-target-verify](../../solforge-workflow-software-target-verify/SKILL.md): Build and verify exact target artifacts with explicit cross-build, emulator, simulator, and real-target evidence tiers.
