# Software workflows

Select the capability matching the actual task. Read its entrypoint only when needed.

- [solforge-workflow-code-research](../../solforge-workflow-code-research/SKILL.md): Audit a whole codebase or ecosystem for intended architecture, hidden capabilities, inconsistencies, and completion gaps.
- [solforge-workflow-codebase](../../solforge-workflow-codebase/SKILL.md): Investigate a connected repository with file-level evidence, architecture and history analysis, reproducible probes, and repository-specific verification.
- [solforge-workflow-software-build](../../solforge-workflow-software-build/SKILL.md): Create a bounded implementation with explicit writes, tests, rollback, and verification.
- [solforge-workflow-software-compare](../../solforge-workflow-software-compare/SKILL.md): Inspect implementations symmetrically against explicit criteria, evidence parity, and decision sensitivity.
- [solforge-workflow-software-diagnose](../../solforge-workflow-software-diagnose/SKILL.md): Trace behavior, ownership, history, data flow, and failure evidence in the connected repository.
- [solforge-workflow-software-mvp-create](../../solforge-workflow-software-mvp-create/SKILL.md): Turn a product brief or selected research into a PRD, architecture, and working vertical slice.
- [solforge-workflow-software-refactor](../../solforge-workflow-software-refactor/SKILL.md): Produce or execute a behavior-preserving, test-gated, reversible refactor within requested paths.
- [solforge-workflow-software-security](../../solforge-workflow-software-security/SKILL.md): Inspect threat boundaries, unsafe flows, dependencies, exploitability, mitigations, and residual risk.
- [solforge-workflow-software-test](../../solforge-workflow-software-test/SKILL.md): Design and run proportional tests, regression checks, adversarial cases, and reproducible verification.
