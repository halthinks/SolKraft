# Data workflows

Select the capability matching the actual task. Read its entrypoint only when needed.

- [solforge-workflow-data-analyze](../../solforge-workflow-data-analyze/SKILL.md): Execute a reproducible analysis with grain, definitions, assumptions, uncertainty, and decision implications.
- [solforge-workflow-data-model](../../solforge-workflow-data-model/SKILL.md): Build and validate a transparent model with baselines, holdouts, sensitivity, drift, and limitations.
- [solforge-workflow-data-validate](../../solforge-workflow-data-validate/SKILL.md): Audit completeness, quality, leakage, calculations, provenance, and whether evidence supports the claims.
- [solforge-workflow-data-visualize](../../solforge-workflow-data-visualize/SKILL.md): Build evidence-linked charts and an explanatory narrative matched to audience and decision use.
