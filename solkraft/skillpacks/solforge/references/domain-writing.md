# Writing workflows

Select the capability matching the actual task. Read its entrypoint only when needed.

- [solforge-workflow-whitepaper-to-readme](../../solforge-workflow-whitepaper-to-readme/SKILL.md): Convert an evidence-rich report into a progressive-disclosure README package with source-bound claims, verified commands and links, preserved user scope boundaries, supporting docs, and a compression ledger.
- [solforge-workflow-writing-draft](../../solforge-workflow-writing-draft/SKILL.md): Produce the selected document package with evidence, visuals, citations, review gates, and exports.
- [solforge-workflow-writing-factcheck](../../solforge-workflow-writing-factcheck/SKILL.md): Verify material claims against authoritative sources and expose unsupported, stale, or disputed statements.
- [solforge-workflow-writing-outline](../../solforge-workflow-writing-outline/SKILL.md): Create a source-aware argument and section architecture matched to audience, purpose, and evidence.
- [solforge-workflow-writing-review](../../solforge-workflow-writing-review/SKILL.md): Audit logic, support, contrary evidence, clarity, structure, citations, and audience fit before revision.
