# SolForge Perfection

Run a long, independent, progress-first product-completion phase that plans its own work, executes repairs, exercises real user journeys, inspects actual deliverables, and repeatedly replans from easy high-leverage failures toward deeper and more complex ones. Use after broad Research and Mastery phases have converged, or whenever a selected program needs sustained implementation rather than more analysis. Works for any repository or connected repository ecosystem, including applications, libraries, services, websites, CLIs, games, data systems, agent systems, hardware workflows, and mixed platforms.
