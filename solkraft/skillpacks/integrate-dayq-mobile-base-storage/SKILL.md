# Integrate DayQ Mobile and Base Storage

Read [MOBILE_BASE_STORAGE_CONTRACT.md](references/MOBILE_BASE_STORAGE_CONTRACT.md). Platform owners retain movement/damage; inventory retains contents; building retains placement; this skill defines storage interfaces and load consequences.

## Workflow

1. Define platform hardpoints, bay/opening geometry, access, loading path and lift/tool needs.
2. Define container/rack compatibility, restraints, locks, power/data/environment connections and permissions.
3. Calculate added mass, center of mass, inertia, suspension/actuator load, drag, clearance and stability.
4. Define unsecured-load movement, noise, collision damage, spill, detachment and jettison.
5. Define external versus internal exposure, armor/cover, fire, flooding, contamination and temperature.
6. Define install/remove/repair jobs and transport logistics.
7. Test movement, crash, rollover/fall, damage, authority, late join, restart and platform performance.

## Completion

Deliver interface/hardpoint graph, load calculations, compatible families, jobs, authority/persistence adapters and representative platform evidence.
