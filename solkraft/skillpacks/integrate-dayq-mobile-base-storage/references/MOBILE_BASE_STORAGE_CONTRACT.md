# Mobile and Base Storage Contract

Required: platform owner, hardpoint/bay/opening, compatibility key, restraint, maximum static/dynamic load, access, tools/lift, power/data, environment, permissions, added mass/center of mass/inertia, motion/crash rules, damage/detachment/spill, installation, repair and persistence.

Exoskeleton and mech storage remains constrained by frame strength, balance, actuator capacity, energy, heat, silhouette and combat exposure.
