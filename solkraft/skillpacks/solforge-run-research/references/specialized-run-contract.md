# Specialized Run contract

Validate the complete parent chain, exact execution-plan file, proposal receipt, creation receipt, selected strategy, and locked execution-quality contract before approval, start, and every resume. Reject any reduction in testing, validation, adversarial effort, evidence, rollback, checkpoints, stop conditions, or acceptance. Call `solforge_request_approval`, direct `start_run`, `steer_run`, `pause_run`, `resume_run`, and `record_acceptance` in the same order and with the same fail-closed semantics as SolForge Run. Perform one bounded plan unit per lease and persist evidence before checkpointing. Material steering revokes approval. The approved plan and locked quality contract are the execution authority; Goal state is ignored. Never call partial progress complete.

When `<PROFILE>=ULTRA`, this specialization MUST execute the shared `$solforge-run-ultra` preflight at approval, start, every resume, and before every native dispatch. The specialized runner cannot bypass or weaken the canonical capsule hash, fresh native capability attestation, complete budget-contract hash, armed kill-switch receipt, minimum two-agent proof, single-active-lease rule, SHA-chained lease ledger, or Ultra acceptance audit. Persist those bindings and every checkpoint receipt in the same state ledger; missing or stale evidence fails closed.
