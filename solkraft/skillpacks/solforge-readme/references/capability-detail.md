# SolForge README

Transform evidence-rich whitepapers, technical reports, selected research, and architecture documents into high-quality Git repository README packages with progressive disclosure, source-bound claims, supporting docs, validated links and commands, preserved security and user scope boundaries, and a compression ledger. Use when an user asks to create, rewrite, improve, audit, or derive a README from deeper source material without losing the system's real capabilities or limitations.
