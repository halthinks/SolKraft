# Audit DayQ Body and Locomotion

Read [BODY_LOCOMOTION_AUDIT_CONTRACT.md](references/BODY_LOCOMOTION_AUDIT_CONTRACT.md). Inspect source-bound evidence rather than summaries.

## Workflow

1. Inventory runtime owners, plugins, libraries, skeletons, animation assets, physics profiles, schemas, tests and evidence.
2. Trace input through authority, movement, capability, animation, reaction, health, equipment and persistence.
3. Verify no duplicate movement, wound, item, damage or save authority exists.
4. Run the representative matrix across body profiles, loads, injuries, surfaces, weather, weapons, traversal and exoskeletons.
5. Validate two-client/dedicated-server authority, correction, reconnect, restart, migration, corruption and anti-cheat.
6. Validate first/third-person, controller, accessibility and motion-sickness controls.
7. Profile representative players/AI and animation/physics LODs.
8. Mark every gate passed, failed, blocked or not tested. Do not infer completion.

## Output

Deliver an audit report with exact build, versions, hashes, routes, metrics, defects, repairs, regressions, open gates and bounded acceptance status.
