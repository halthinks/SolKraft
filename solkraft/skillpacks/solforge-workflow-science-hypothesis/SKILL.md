# Develop testable hypotheses

Use the [native execution contract](../solforge/references/native-execution.md) once per task.

Establish the research question as actually posed, the evidence already selected or supplied, the conditions it was gathered under, and the acceptance criteria for the hypothesis set. Read the sources behind load-bearing claims rather than trusting summaries of them. If the evidence base is thin or one-sided, say so and mark the resulting hypotheses as provisional instead of inflating their support.

For each hypothesis, state the proposed mechanism or relationship, the conditions under which it should hold, and a prediction specific enough to be wrong: an observable quantity, direction, or effect size that follows from the hypothesis and not from doing nothing. Generate genuinely competing alternatives, including a null or baseline explanation and at least one rival that accounts for the same observations by a different mechanism; a set of rephrasings of one idea is not a set of alternatives. Attach a falsifier to each — the result that would reject it — and note which observations distinguish the rivals from each other rather than from strawmen.

Verify the set against the evidence before reporting: every hypothesis should be consistent with what is already observed, each prediction should be checkable with feasible methods and data, and each falsifier should be reachable rather than unfalsifiable in principle. Anti-patterns: a prediction so vague any outcome confirms it; a falsifier that requires data nobody can obtain; a hypothesis already contradicted by a cited source presented as open; and retrofitting hypotheses to known results while presenting them as a priori. Keep established fact, inference, and speculation distinct.

Report the hypothesis set with predictions, falsifiers, discriminating observations, and the evidence each one rests on, plus unresolved gaps in the evidence base. Use [experiment design](../solforge-workflow-science-experiment/SKILL.md) when a selected hypothesis needs methods, controls, and measurements specified before execution.
