# Multiplayer and persistence contract

Required technical proof areas:

1. Large persistent world.
2. Thousands of build pieces.
3. Construction/destruction replication.
4. Offline persistence.
5. Vehicles under latency.
6. AI simulation at distance.
7. Dynamic defense grids.
8. Drone control.
9. Bunker interiors.
10. World streaming.
11. Authoritative inventory.
12. Anti-duplication.
13. Server crash recovery.
14. Database migrations.
15. Anti-cheat.

Baseline benchmark: 60 players, 30 active vehicles, 10,000 persistent construction pieces, and 200 relevant AI while maintaining the separately locked server tick target.

Every spike must define configuration, dataset, network profile, duration, threshold, evidence, result, bottleneck, and remediation.
