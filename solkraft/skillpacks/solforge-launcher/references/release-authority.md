# Release authority

Local inspection, generation, builds, tests, checksums, local signatures with user-supplied test keys, SBOMs, provenance drafts, and release previews are local actions.

Commit, push, release creation, registry upload, externally trusted signing, Apple notarization, Microsoft signing services, store submission, hosting, deployment, purchases, credential changes, and disclosure are separate final actions. Bind each exact effect, account, target, artifact hash, recovery behavior, and acceptance test to its accepted route and plan receipt. Never collapse “ready to publish” into “published.”
