# Build DayQ Wearable Storage

Read [WEARABLE_STORAGE_CONTRACT.md](references/WEARABLE_STORAGE_CONTRACT.md). Clothing owns seams/coverage/fit; physical inventory owns contents, capacity, slots, access transactions, load paths and spills.

## Workflow

1. Define body-size fit, attachment points, frame/belt/strap load paths and adjustment ranges.
2. Define compartments, openings, quick slots, external attachments, hydration, weapons/tools and restricted hazard placement.
3. Calculate supported/unsupported mass, offsets, sway, bulk, snag, silhouette and noise.
4. Map load to movement, stamina, vaulting, prone, climbing, swimming, fall arrest and injury.
5. Define access posture, hands, animation, interruptions and combat readiness.
6. Define fabric/frame/zipper/buckle/strap damage, wet mass, contamination, spill and field repair.
7. Integrate exoskeleton connectors without erasing inertia, bulk, power or frame limits.
8. Validate fit, controller UI, two-client transfers, death/drop/recovery and restart.

## Completion

Deliver wearable family, fit/load curves, slot graph, components, animations, recipes, assets, authority/persistence mappings and test evidence.
