# Wearable Storage Contract

Record body fit, empty dimensions/mass, flexible capacity, opening, compartments, typed slots, closure, frame, shoulder/hip load transfer, adjustment, sway, balance, bulk, snag, noise, access time, posture, hands, retention, wetness, condition and exo interface.

Failure must localize: a torn side pocket spills only its contents; a broken hip belt shifts supported mass; a jammed zipper traps the affected compartment; a frame failure changes load transfer. Aggregate pack condition cannot erase localized state.
