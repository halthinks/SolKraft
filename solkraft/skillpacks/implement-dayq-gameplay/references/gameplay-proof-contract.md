# Gameplay proof contract

## Combat release-candidate coverage

Arena, rifle, handgun, melee weapon, armor, bleeding, sound propagation, simple AI, and basic multiplayer. Measure lethality, recoil, movement speed, time to kill, healing time, suppression, stealth readability, and tactical-versus-twitch balance.

## Survival release-candidate coverage

One-hour simulated journey containing hunger, thirst, temperature, wounds, infection, carried weight, and contaminated water. Log decisions caused by each pressure. Combine or remove any pressure that only demands periodic meter refill.

## Routine change

- compile the affected target;
- execute one focused smoke route;
- record the command and result.

## Subsystem milestone

- run focused automation for the mechanic;
- execute one representative PIE route;
- retain at most one representative screenshot, log, or metric capture;
- list nonblocking defects as deferred.

## Integration or release evidence

- build identifier and configuration;
- deterministic or recorded route;
- input trace where feasible;
- metrics with units;
- screenshots/video for readability claims;
- logs and crash output;
- pass/fail table;
- focused adjacent regression results at integration milestones, full regressions at release;
- tuning changes and rationale.
