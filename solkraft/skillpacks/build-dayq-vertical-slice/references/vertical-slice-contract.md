# First-region vertical-slice contract

Target content, built in dependency order:

- spawn area;
- starter settlement;
- dangerous scavenging route;
- faction checkpoint;
- repairable vehicle;
- outpost-building location;
- industrial site;
- elite compound;
- defense grid;
- primitive suppression mission;
- bunker teaser.

Experience checkpoints, validated when the playable route reaches them:

- first 10 minutes;
- first hour;
- first 5 hours;
- first 20 hours;
- first clan milestone;
- first major loss and recovery;
- first elite-compound raid.

For the active checkpoint, define the player objective, one meaningful decision, the required systems, a failure/recovery path, and the focused smoke route. Compile and play it before expanding scope. At integration milestones, add telemetry and pass criteria for the checkpoints reached so far. Defer future checkpoint matrices and full-arc evidence until those horizons are playable.
