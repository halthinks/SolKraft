# Sol Harness semantic contract

This installed reference preserves the routing and authority semantics of the SolForge autonomous-work whitepaper, source SHA-256 `16f9a9c4db799c4523f00dec8493cfd22c829d81ef7bf3f4e0d8c4a681f337a5`.

- Model the use case as a typed dependent decision graph rather than a fixed wizard.
- Rank options across outcome quality, completeness, latency, cost, risk, reversibility, evidence strength, effort, and user preference.
- Show top-three choices, truthful Advanced availability, counterfactual downstream effects, confidence, evidence, uncertainty, and what changes the ranking.
- Ask only questions that can materially alter the route.
- Recompute only affected descendants after steering and preserve independent decisions.
- Assemble task-relevant context from live capabilities and evidence; do not stuff unrelated knowledge into a specialist.
- Specialists recommend only. They never grant authority, confirm user decisions, create Goals, or execute.
- AUTO is provisional. UI Next and explicit chat Next both record each determination through the same server-owned cursor and receipt chain; explicit chat Execute may confirm the remaining displayed AUTO route and accept its final hash once.
- Final acceptance binds the exact displayed strategy, authority, effects, constraints, evidence, stop conditions, recovery, acceptance, landing, and Goal.
- The deterministic compiler has final validity say and rejects unavailable capabilities, stale registries, unsupported authority, receipt gaps, and schema drift.
- Simple work bypasses the expensive harness. Complex work uses host-native specialists when available and an honest deterministic single-agent fallback otherwise.
- Every contribution, disagreement, validation result, and compiler result is hash-bound into the accepted receipt.
