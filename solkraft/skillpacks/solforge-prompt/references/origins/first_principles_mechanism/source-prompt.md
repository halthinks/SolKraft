# First-Principles Mechanism

Version: 1.1.0
Status: candidate

## Operating idea

Rebuild from irreducible entities, states, flows, causes, and falsifiable mechanisms.

## Applicability gate

1. Use only when a causal explanation or mechanism-level intervention would materially improve the decision or solution.
2. Require observations and system boundaries sufficient to instantiate at least two testable candidate mechanisms or one directly evidenced mechanism.
3. Route away when a validated procedure already answers the need and causal reconstruction adds no decision value.

## Sol execution contract

1. Select and declare the domain-fit mechanism mode before decomposition: physical or causal, software or state-transition, organizational or incentive, economic or flow, or epistemic or evidence; use only the modes warranted by the problem.
2. Within the selected mode, separate observations from inferences and enumerate the relevant entities, states, transformations, information, resources, incentives, timescales, and failure mechanisms without force-fitting physical terminology.
3. For every major causal claim identify the transmission from cause to consequence, competing explanations, operating scale, removal behavior, evidence, and epistemic status.
4. Build only evidence-consistent competing mechanisms with initial conditions, transitions, feedback, failure boundaries, distinct predictions, and minimal interventions.
5. Prefer causal compression only after discrimination; if available evidence cannot choose among viable mechanisms, return `MECHANISM_UNDERDETERMINED` and specify the minimum discriminating observation, experiment, trace, or intervention required.
6. When evidence discriminates, reconstruct the solution from the minimal supported mechanism, derive falsifying tests, and expose remaining unverified assumptions.

## Observable output contract

1. Declared domain-fit mechanism mode and observation-to-inference boundary.
2. Entity, state, flow, incentive, or evidence map appropriate to that mode.
3. Competing-mechanism table with distinct predictions and falsifiers.
4. Selected minimal mechanism with intervention tests, or a `MECHANISM_UNDERDETERMINED` packet naming minimum discriminating evidence.

## Shared control boundary

This origin inherits authority, evidence, checkpoint, Safe Pause/Resume, truthful-blocking, and acceptance rules from solforge-origin-controls-v1. It does not grant execution authority.
