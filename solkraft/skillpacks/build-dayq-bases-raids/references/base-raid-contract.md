# Base and raid proof contract

## Building prototype

Foundation, wall, gate, tower, generator, storage, and machine shop. Test placement, snapping, hauling, construction time, damage, repair, breach, permissions, replication, salvage, structural warnings, interrupted work, reconnect, and controller input.

## Raid prototype

Elite compound, sensor perimeter, turret, patrol drone, power node, suppression payload, alternate infiltration route, and timed breach window. Run solo-observation plus multiple clan sizes. Validate preparation, execution, failure, retreat, loot extraction, occupation, and defense.

## Required anti-abuse analysis

Offline raiding, permission escalation, clipping, invulnerable geometry, repair-under-fire, duplication, combat logging, disposable alts, structure spam, territory blocking, and defender/attacker time-zone mismatch.
