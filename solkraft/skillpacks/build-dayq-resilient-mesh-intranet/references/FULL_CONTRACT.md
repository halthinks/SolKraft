# Resilient Mesh, LoRa-Class Data, and Base Intranet Contract

## Layer and device doctrine

The communications stack is: physical proximity acoustics; conventional live radio voice; low-bandwidth LoRa-class mesh data; physical base intranet; long-range backhaul. LoRa mesh never carries normal live voice. Standard LoRaWAN star-of-stars behavior and DayQ's original decentralized LoRa-PHY-inspired protocol remain distinct.

Support persistent pocket/belt/pack/helmet/exo/vehicle nodes, sensor/trip/weather/medical/asset/convoy/cache beacons, repeaters, masts, solar/hydrogen ridge relays, gateways, hardened command and captured secure gateways. Each declares physical mass/size/slots, antenna/interface, power/sleep, transmit/receive policy, processing/storage, environment/condition/repair, security and signature.

Services declare payload class, priority, expiry, reliability/retry, size, privacy, routing/cache/relay policy and forgery/intercept/delay/replay behavior for text, orders, acknowledgements, uncertain position, distress, sensors/weather/contamination, base alarms, patrol/convoy check-ins, tactical markers, requisitions/production summaries, authentication, dead drops, delayed intelligence, and health/power reports.

## State, propagation, routing, and security

Node state includes stable hardware/instance/owner/network IDs, protocol revision, peers, channels, neighbors, hop budget, queues/congestion/duty cycle, packet age/attempts, link uncertainty, antenna/power/tamper, security tier/credential references, capture/compromise/revoke/quarantine, time quality, gateway/intranet, uncertain last location, and persistence revision. Packets have stable origin/scope/server payload reference, priority/times, hop budget, opaque route digest, delivery state, and optional security envelope. Secrets/payloads never reach unauthorized clients.

Server link evaluation uses distance, terrain/elevation, urban/material obstruction, antenna height/type/orientation, device classes, justified weather, interference, abstract countermeasures, condition and congestion through cached cells/queries/tags and event recalculation—not radio-wave simulation. UI communicates uncertainty.

Support direct, multihop, store-forward, preferred/priority relay, expiration, partition/reunion, duplicate/loop suppression, congestion backoff, low power/silence/emergency, capture/replay/spoof/credential compromise, stale intelligence and damaged relays. Loss must physically affect coverage, logistics, sensors, risk and cached traffic.

Security tiers range open/manual codes through risky conventional crypto, physically distributed local keys, hardware-rooted nodes and rare post-quantum enclave equipment. Security costs power/weight/setup/key logistics/interoperability/recovery/specialists. Cyber behavior remains abstract gameplay with quarantine/rekey/revoke/recovery, never real exploitation.

## Base intranet and Unreal

Physical services include cable, switches/routers/APs, mesh/radio gateways, directory/time, maps/intelligence, inventory/production/medical terminals, cameras/sensors/access/logging, messaging/backups, secure enclave, consoles and provisioning. Every service depends on power, hardware/storage/cooling, permissions, software/security and explicit damage.

Implement a server-authoritative subsystem with Data Assets for devices/antennas/protocol/services/security; unique persistent instances; existing power/condition/repair/ownership/inventory/persistence components; cached links; relevance-filtered events; strategic unloaded queues; and adapters to intranet, acoustic, AI, clan, map and radio. Debug nodes/routes/queues/congestion/power/trust/delivery without exposing secrets.

## Acceptance

Prove direct and multihop delivery, predictable obstruction, partition from destroyed/depowered relay, no-duplicate delayed store-forward, expiry, priority/congestion, capture/revoke, protected recipient filtering, late join/disconnect/restart/rollback/migration, dense CPU/memory/queue/bandwidth budgets, and inability to convert mesh into global surveillance or live voice. Test replay, forged identity/recipient, infinite queues/rewards, logout capture avoidance, permissions and crash recovery.
