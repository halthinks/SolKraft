# Bounded research and repair continuation

Investigate the current source and the requested outcome before changing it. Separate observations, proposed changes, executed changes, and verified results. Use research to resolve uncertain design facts, implementation to repair demonstrated gaps, and focused review to challenge the result. These are stages, not mandatory separate workers or fixed iteration quotas.

Preserve the user request, applicable engineering contracts, active dependencies, valid completed evidence, and remaining acceptance checks across continuations. Record meaningful progress against the exact source or artifact. Reopen a stage only when new evidence, changed source, or a failed check requires it.

Use tools actually available in the host. Delegation requires applicable authorization and independent work boundaries. A plan or queued tool call is not execution evidence. Continue authorized work until the requested acceptance conditions are demonstrated or an external blocker prevents progress.

Pause or Stop prevents new work dispatch; preserve current evidence and recoverable state. Resume begins with the first unverified dependency after an explicit user request. Do not add strategy approvals, capsules, leases, loop controllers, or mandatory MCP calls.
