# Unreal Asset Acceptance Contract

Use the native DayQ Unreal MCP production/validation skill. Import into project naming/folder conventions; create or update Data Assets and gameplay metadata; validate scale, materials, LODs, collision, sockets, interactions, destruction, repair, salvage, navigation, environmental transitions, audio/VFX, inventory/construction integration, replication authority, persistence/migration, crash recovery, and performance budgets.

Acceptance requires a connected editor, successful compilation, PIE or the required dedicated-server/client route, automated tests, observable gameplay evidence, logs, metrics, defects/repairs, regression results, and hashes. Source compatibility or compilation alone is not acceptance. If Unreal 5.8 or MCP is unavailable, mark the job `blocked` at the live Unreal gate and preserve all upstream evidence.
