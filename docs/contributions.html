CONTRIBUTIONS SHOWCASE

Impact, not just commits.

SolKraft recognizes the different ways an open-source system gets better. Code matters. So do architecture ideas, testing, research, issue discovery, documentation, design, and community help. This showcase records the high-level outcomes contributors helped create.

ARCHITECTURE

Executable capability contracts

Skills can declare typed inputs/outputs, effects, capability/resource requirements, verification, and executable fixtures.

ROUTING

Safer capability selection

Contract-aware admissibility, whole-route validation, typed dataflow, and explicit blocked states make selection easier to inspect.

VERIFICATION

Regressions become visible

Reusable CI runs contract checks, fixture assertions, packaging, installed MCP verification, and broad routing regression suites.

COMMUNITY

Ideas count as contribution

Recognition is based on project impact, not whether the contribution arrived as a pull request.

SUPPORT

Clear support and contribution paths

Users can submit guided support issues, nominate contributors, and distinguish help requests from code contributions.

OPEN SOURCE

Public evidence and attribution

Contributors, ratings, nominations, changelog entries, and validation receipts are visible and reviewable.
