FROM A REQUEST TO USEFUL WORK

Your agent does the work. SolKraft supplies the method.

A skill is a reusable procedure with instructions and supporting resources. The solforge skill contains the orchestration and semantic routing machinery; it is also a node in the selection graph. Specialist skills supply the methods for research, building, testing, writing, and engineering. Capability-preserving execution supplies the adaptive execution loop: frame the outcome, map dependencies, schedule safe work, preserve evidence, repair failures, and verify completion. It is an instruction-based execution layer, not a hidden Python scheduler.

How the semantic parser and graph actually work

Read the requested actions

The deterministic parser uses scoped rules, concept aliases, domain context, and lexical ranking. It separates requested stages while treating quoted instructions, exclusions, and recognised completed or deferred work as context.

Select and order skills

The tested semantic core matches stages to workflow nodes. Conditional graph edges describe when a supporting procedure is useful. Explicit skill IDs support direct selection. Recognised unmatched stages can use catalog matching; ambiguity can remain unresolved.

Keep the limits visible

This is a heuristic parser, not an LLM call. Rule scores are relative rankings, not probability estimates. The graph includes catalog-only skills without inventing dependencies. A proposed route never grants permission or executes a job.

Catalog search on this static site is keyword filtering. Custom semantic composition runs in your connected server. The example is real, precomputed parser output and is labelled separately from a live response.

PUT IT TO WORK

Install once. Ask normally.

The plugin gives a compatible local agent five MCP tools and a small skill that explains when to use them. The Python package supplies the complete bundled catalog and router. Start a new session after installation.

CODEX · LOCAL

Install the runtime + plugin

python -m pip install "git+https://github.com/halthinks/SolKraft.git"
codex plugin marketplace add halthinks/SolKraft --sparse .agents/plugins --sparse plugins/solkraft
codex plugin add solkraft@solkraft

Python 3.11+ must be installed so solkraft is on Codex’s PATH. Use the same environment for installation and launch.

How it compares with other projects

skills.sh focuses on discovering and installing skills. Superpowers supplies an opinionated development methodology and agent workflows. SolKraft combines a multi-domain catalog, deterministic compound-request routing, inspectable relationships, and selective retrieval through REST and MCP. These approaches can coexist; there is no measured claim here that SolKraft beats either project.

ILLUSTRATED GUIDE
Which connection should I use?

Local Codex: install the runtime and plugin. No Render deployment or API key is needed for local stdio MCP. Your application or script: use REST JSON endpoints. A remote compatible agent: use HTTPS MCP with supported authentication. Just browsing: inspect and copy a skill; no server is needed.

The plugin configures the host. MCP carries tool calls. REST carries HTTP requests. Skills supply methods. Your agent carries out the work.
