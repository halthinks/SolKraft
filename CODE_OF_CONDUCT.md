# Code of Conduct

We want SolKraft to be a welcoming, practical project. Be respectful, assume good intent, focus criticism on ideas and changes, and make room for different experience levels and communication styles. Harassment, discrimination, personal attacks, and publishing private information are not acceptable.

Maintainers may edit, reject, or remove contributions that violate these expectations. For concerns, contact the repository owner privately through GitHub.
